# SkillBridge

A robust MERN-stack platform designed to seamlessly connect non-governmental organizations (NGOs) with global volunteers through integrated dashboards and interactive management tools. Developed as part of the **Infosys Springboard Virtual Internship 6.0** (09/2025 - 11/2025) by an Agile team of 6 engineers.

---

## 🚀 My Contributions (Frontend Developer)
While working within an Agile engineering workflow, I focused heavily on UI/UX optimization, version control, and core real-time feature implementation:
* **Real-Time Communication:** Architected a bidirectional real-time chat system and an automated notification layer, successfully managing complex asynchronous application states.
* **UI/UX Engineering:** Developed fully responsive, highly performant frontend interfaces using React.js and Tailwind CSS, reducing redundant rendering overhead.
* **API Integration:** Consumed and integrated complex backend REST APIs to seamlessly connect our frontend components with database operations.

## 🛠️ Tech Stack
* **Frontend:** React.js, CSS Modules, JavaScript (ES6+), Figma (UI/UX Design)
* **Backend:** Node.js, Express.js, REST APIs
* **Database & Real-time:** MongoDB, WebSockets / Socket.io
* **Workflow & Tools:** Git, GitHub, Agile/Scrum

## 💻 Installation & Setup

1. **Clone the repository:**
```bash
   git clone [https://github.com/YOUR_USERNAME/VolunteerConnect.git](https://github.com/YOUR_USERNAME/VolunteerConnect.git)

2. Install Frontend Dependencies:

    Bash
   # Navigate to frontend folder and install
   cd frontend
   npm install

3. Install Backend Dependencies:

    Bash
   # Navigate to backend folder and install
   cd ../backend
   npm install

4. Environment Variables:
    Create a .env file in the backend directory and add your MongoDB URI, Port, and secret keys.

5. Run the Application:

    Bash
   # In frontend directory
   npm start
   # In backend directory
   npm run dev
